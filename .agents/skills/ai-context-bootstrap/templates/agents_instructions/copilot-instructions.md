# Copilot Instructions

## Project context: `.ai-context/`

This repository uses `.ai-context/` as the canonical project context.

### Mandatory behavior

- Read `.ai-context/README.md` first and follow its reading order.
- Do not read source code before consuming the necessary `.ai-context/` docs.
- Only read files relevant to the task.
- Do not invent project details; use `N/A` or `Pending` when unknown.

### When context is missing

- Prefer updating `.ai-context/` with minimal, structured changes (headings, short notes).
- Ask at most 3 questions if blocked.

### Output expectations

- Provide a short summary + a checklist of changes.

## Language

- Use Spanish for all user communication.
- Generate all outputs (documentation, comments, summaries, code comments, reports) in Spanish.
- Do not switch language unless the user explicitly requests it.
